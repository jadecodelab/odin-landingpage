# Odin Landing Page

This is a practice landing page built for The Odin Project Foundations curriculum. The goal of this project is to recreate a provided landing page design using HTML and CSS, with a focus on layout, spacing, typography, colors, and Flexbox.

## What I Practiced

- Building a page from a visual reference
- Creating a header and navigation layout
- Using Flexbox to arrange page sections
- Styling a hero section, information cards, quote section, call-to-action area, and footer
- Working with colors, font sizes, spacing, borders, and buttons

## Future Plans

This version is mainly for practicing the Odin Project assignment. Later, I plan to come back and turn it into a real landing page with my own content, images, and design choices.
